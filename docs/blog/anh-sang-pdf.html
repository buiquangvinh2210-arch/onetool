Ảnh sang PDF online — ghép JPG/PNG thành một file

Scan CCCD, biên lai, bài tập bằng điện thoại? Chuyển ảnh sang PDF để nộp một file gọn, đúng thứ tự trang.

Hỗ trợ JPG, PNG, WebP… Chọn khổ vừa ảnh / A4 / Letter, sắp xếp trang rồi tải PDF.

Ảnh → PDF miễn phí Thêm nhiều ảnh, sắp thứ tự, tạo PDF ngay trên trình duyệt. Mở Ảnh sang PDF →

Các bước

  1. Mở Ảnh sang PDF.
  2. Thêm một hoặc nhiều ảnh.
  3. Kéo sắp thứ tự trang, chọn khổ trang.
  4. Tạo PDF và tải về (xem trước nếu có).

Mẹo nộp hồ sơ

  • Ảnh iPhone HEIC: đổi JPG trước với HEIC sang JPG.
  • File quá nặng: nén PDF trước khi gửi.
  • Cần chữ ký: ký PDF online.
  • Chiều ngược lại (PDF → ảnh): PDF sang ảnh.

Câu hỏi thường gặp

Có miễn phí không?
Có. Ghép ảnh thành PDF miễn phí, không bắt buộc đăng ký.

File có upload không?
Xử lý trên trình duyệt — phù hợp ảnh giấy tờ.

Ghép được bao nhiêu ảnh?
Nhiều ảnh; máy yếu / ảnh rất lớn có thể chậm hơn.
