Cách ghép PDF online không cần phần mềm

Cần nộp một file duy nhất (CV + bằng cấp, hợp đồng + phụ lục)? Bạn có thể ghép PDF online ngay trên trình duyệt — không cài Adobe, không bắt buộc đăng ký.

Nhiều người vẫn gửi 4–5 file PDF riêng lẻ, khiến người nhận phải mở từng file và tự đoán thứ tự. Cách gọn hơn là ghép PDF (merge PDF) thành một tài liệu rồi tải về máy. Bài này hướng dẫn thêm cách tách, xóa, xoay trang và nén file.

Vì sao nên ghép PDF trên trình duyệt?

  • Không cần phần mềm — dùng được trên Windows, macOS và điện thoại, không phải cài Adobe Acrobat.
  • File không rời máy bạn — trên OneTool, việc gộp PDF chạy trong trình duyệt, file không được gửi lên server.
  • Miễn phí, không watermark — không bắt buộc tài khoản.
Dùng ngay công cụ Ghép PDF Kéo thả từ 2 file trở lên, sắp thứ tự, bấm Gộp rồi tải về. Mở Ghép PDF online →

Những tình huống hay cần ghép PDF

  • Hồ sơ xin việc — CV, thư xin việc, bằng cấp và chứng chỉ gộp thành một file.
  • Hồ sơ dự thầu — giấy phép kinh doanh, báo cáo tài chính, hợp đồng tương tự phải nộp đúng thứ tự yêu cầu.
  • Hóa đơn cuối tháng — gom hóa đơn điện tử của nhiều nhà cung cấp thành một file gửi kế toán.
  • Tài liệu scan nhiều lần — máy scan thường xuất mỗi lần quét thành một file, nên bộ hồ sơ 20 trang có thể nằm trong 5–6 file.

Nếu một phần hồ sơ là ảnh chụp điện thoại, hãy chuyển ảnh sang PDF trước rồi mới ghép.

Hướng dẫn ghép nhiều file PDF thành một

  1. Mở trang Ghép PDF online của OneTool.
  2. Kéo thả các file PDF vào khung tải lên, hoặc bấm vào khung để chọn nhiều file từ máy.
  3. Bấm + Thêm PDF nếu còn thiếu file; công cụ cần ít nhất 2 file.
  4. Dùng nút ↑ và ↓ cạnh mỗi file để đổi thứ tự, nút × để bỏ file chọn nhầm.
  5. Bấm Gộp PDF, chờ xử lý xong rồi bấm Tải file.

Toàn bộ trang của từng file được nối liên tiếp theo thứ tự trong danh sách. File kết quả có tên mặc định là merged.pdf, nên hãy đổi tên trước khi gửi.

Mẹo sắp xếp và đặt tên file để không sai thứ tự

Công cụ gộp theo thứ tự hiển thị trong danh sách, không tự sắp theo tên hay ngày tạo file. Vì vậy, hãy kiểm tra danh sách một lượt trước khi bấm Gộp.

  • Đánh số đầu tên file bằng hai chữ số, ví dụ 01-CV.pdf, 02-bang-cap.pdf, vì nhiều trình quản lý file xếp "10" trước "2".
  • Đặt tên file kết quả rõ ràng, ví dụ Nguyen-Van-A_Ho-so.pdf.
  • Mở file đã tải để chắc không có phần nào bị đảo.

OneTool hiện chưa có chức năng kéo thả từng trang bên trong một file. Muốn đổi thứ tự trang, bạn tách file thành các phần rồi ghép lại theo thứ tự mong muốn.

Tách trang PDF: chỉ lấy phần cần gửi

Công cụ Tách PDF online lấy một hoặc vài trang ra file mới, ví dụ chỉ gửi trang điều khoản thay vì cả hợp đồng. Bạn tải file lên, nhập số trang vào ô Trang cần giữ rồi bấm Tách PDF.

  • Trang lẻ cách nhau bằng dấu phẩy (2,5,9), khoảng trang dùng dấu gạch ngang (1-3), có thể kết hợp như 1-3,5.
  • Số trang tính từ trang đầu của file, không theo số in ở chân trang.
  • Các trang luôn được xuất theo thứ tự tăng dần, trang nhập trùng chỉ xuất hiện một lần.

Mỗi lần tách tạo ra một file chứa các trang đã chọn. Muốn tách file PDF thành từng trang riêng, bạn chạy lại công cụ nhiều lần, mỗi lần nhập một số trang.

Xoay trang và xóa trang thừa

Bản scan lộn ngược hoặc nằm ngang là lỗi hay gặp khi ghép hồ sơ. Công cụ Xoay PDF / xóa trang cho chọn góc xoay 90°, 180° hoặc 270° và trang cần xoay, ví dụ 1,3-5.

  • Để trống ô Trang xoay thì mọi trang đều được xoay.
  • Góc xoay được cộng vào hướng hiện tại theo chiều kim đồng hồ; trang lộn ngược chỉ cần xoay 180°.
  • Ô Trang cần xóa dùng để bỏ trang trắng hoặc trang nhầm, ví dụ 2,4; có thể xoay và xóa trong cùng một lần.

Hãy giữ lại bản gốc nếu sau này còn cần các trang đã xóa.

Ghép 2 trang thành 1 trang có được không?

Ghép 2 trang thành 1 là đặt hai trang cạnh nhau trên một mặt giấy. OneTool chưa hỗ trợ việc này, vì công cụ Ghép PDF chỉ nối các file.

Cách thay thế là mở PDF bằng Chrome hoặc Edge, nhấn Ctrl+P, chọn lưu dưới dạng PDF và đặt số trang trên mỗi tờ (Pages per sheet) là 2. Tên mục có thể khác đôi chút tùy trình duyệt.

Giữ file đủ nhẹ để gửi email, Zalo

Dung lượng file gộp gần bằng tổng các file đầu vào, nên ghép nhiều bản scan thường tạo ra file nặng. Khi cần, hãy dùng Nén PDF online trước khi gửi.

  • Mức Ít nén chỉ tối ưu cấu trúc file, giữ chữ tốt nhất nhưng thường giảm ít.
  • Mức Khuyến nghị và Nén mạnh chuyển từng trang thành ảnh JPEG, giảm nhiều nhưng chữ không còn bôi đen hay tìm kiếm được.

Mức dung lượng thường gặp của Zalo và email có trong bài Nén PDF gửi Zalo / email. Nếu vẫn quá nặng, hãy tách thành vài phần rồi gửi lần lượt.

Quyền riêng tư: file được xử lý ở đâu?

Các công cụ ghép, tách, xoay và nén PDF của OneTool dùng thư viện pdf-lib và PDF.js chạy ngay trong trình duyệt. File được đọc và xử lý trên máy bạn, không được gửi lên server OneTool.

Lỗi thường gặp và cách khắc phục

File có mật khẩu

PDF có mật khẩu mở file được mã hóa, nên các trang của nó có thể bị trắng hoặc lỗi trong file ghép. Nếu có quyền, hãy mở file bằng mật khẩu và lưu một bản không khóa (ví dụ in ra PDF bằng trình duyệt, nếu file cho phép in) trước khi ghép. Sau đó có thể khóa lại cả file bằng Đặt mật khẩu PDF.

Trang bị xoay ngang hoặc lộn ngược

Công cụ ghép giữ nguyên hướng trang của file gốc. Ghi lại số trang bị lệch trong file kết quả rồi xoay đúng các trang đó bằng công cụ Xoay PDF / xóa trang.

File quá nặng

Nguyên nhân thường là ảnh scan độ phân giải cao. Hãy nén file đã ghép ở mức Khuyến nghị, hoặc nén riêng từng file nặng trước khi ghép.

Font chữ lỗi, mất dấu tiếng Việt

Ghép PDF sao chép nguyên trang nên không làm thay đổi phông chữ; lỗi font thường có sẵn trong file gốc do xuất PDF mà không nhúng phông. Nếu vậy, hãy xuất lại PDF từ Word với tùy chọn nhúng phông chữ.

Câu hỏi thường gặp

Ghép PDF online có mất phí không?

Không. Ghép, tách, xoay và nén PDF trên OneTool đều miễn phí, không bắt buộc tài khoản.

File PDF có bị tải lên server không?

Không. File được xử lý ngay trong trình duyệt, không gửi lên server OneTool.

Ghép được tối đa bao nhiêu file?

Không có giới hạn cố định, chỉ cần tối thiểu 2 file. Máy yếu hoặc file rất lớn sẽ xử lý chậm hơn.

Làm sao tách file PDF thành từng trang riêng?

Chạy công cụ Tách PDF nhiều lần, mỗi lần nhập một số trang, ví dụ 1, rồi 2, rồi 3.

Có ghép 2 trang thành 1 trang được không?

OneTool chưa hỗ trợ. Bạn có thể in ra PDF bằng Chrome hoặc Edge và đặt số trang trên mỗi tờ là 2.

Làm sao đổi thứ tự trang trong một file PDF?

Tách file thành các phần bằng Tách PDF, rồi ghép các phần lại theo thứ tự mong muốn bằng Ghép PDF.
