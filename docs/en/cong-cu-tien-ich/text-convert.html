How to use the Text Converter

  1. Paste text or open a .txt file.
  2. Choose an action: case, remove accents, slug, clean lines, encode…
  3. Copy or download a TXT — you can move the result back to the source to keep converting.

What is an online text converter for?

The text converter changes letter case (UPPER / lower / Title Case), removes accents/diacritics, creates URL slugs, cleans up spaces and blank lines, encodes URL/HTML or finds & replaces — handy for web content, SEO, CSV and source code.

Accurate accent removal

OneTool normalizes Unicode to NFD, strips combining marks and handles đ/Đ separately. The result works for file names, article slugs or accent-insensitive search.

When to use it

Common use cases:

  • SEO / URLs — slugify a title like "Đặng Thị Hồng" into dang-thi-hong.
  • Data — normalize case and remove blank lines before importing a CSV.
  • Web / code — quick HTML encode, URL encode or Unicode escape.
