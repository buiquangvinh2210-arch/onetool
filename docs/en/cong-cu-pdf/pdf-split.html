How to split a PDF online

          
  1. Upload a PDF file.
  2. Enter the page or page range to extract.
  3. Download the extracted PDF.

        
What is PDF splitting?
Split PDF pulls one or more pages into a separate file — send only the part you need, or break a long document into chapters.
How to split a PDF by pages
Upload the file, enter a page range (e.g. 1-3, 8), run the split and download the result. Page numbers count from the first page of the file.
When to split a PDF
  • Send just the right pages — send only the clauses, not the whole contract.
  • Read on your phone — split scanned books into lighter files.
