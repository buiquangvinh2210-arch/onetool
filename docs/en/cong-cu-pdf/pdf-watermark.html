How to watermark a PDF

  1. Upload file PDF.
  2. Choose a text watermark or a logo image.
  3. Adjust opacity, angle, position / tiling and the page range.
  4. Click Watermark, then download the new PDF.

What is a PDF watermark?

Add a semi-transparent text or logo layer to every PDF page — for drafts, light protection or branding your documents.

Useful options

  • Tiled — covers the whole page, hard to crop out.
  • Page range — e.g. 1-3,5 to watermark only some pages.
  • Logo — a transparent PNG keeps softer edges than JPG.
