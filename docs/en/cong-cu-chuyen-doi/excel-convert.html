How to use Excel to CSV / JSON

          
  1. Choose the direction (Excel→CSV/JSON or CSV/JSON→Excel).
  2. Upload an .xlsx/.xls/.csv/.json file or paste CSV/JSON.
  3. Pick a sheet (if the workbook has several) → Convert → Download.

        
What is Excel ↔ CSV/JSON?
Convert Excel files (.xlsx/.xls) to CSV or JSON and back — entirely in your browser, with no server upload. Ideal for feeding spreadsheets into an API or database, or opening JSON data in Excel.
How to convert Excel to CSV / JSON
Choose Excel → CSV or Excel → JSON, drag in your XLSX file, pick the right sheet if the workbook has several tabs, click Convert, then Download. CSV has a BOM option so Excel opens accented characters correctly.
CSV / JSON to Excel
Choose CSV → Excel or JSON → Excel, then open a file or paste the content. JSON must be an array of objects (one row per item). The result is an .xlsx file that opens in Microsoft Excel, Google Sheets and LibreOffice.
When to use it
  • Working with APIs — export an Excel sheet → JSON for frontend/backend.
  • Reports — system JSON → Excel to send to your manager or accountant.
  • Data cleanup — CSV from another system → edit in Excel → export again.
