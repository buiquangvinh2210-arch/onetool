How to merge PDFs online without software

Need to submit a single file (resume + diplomas, contract + appendices)? You can merge PDFs online right in your browser — no Adobe install, no sign-up required.

Many people still send 4–5 separate PDF files, so the recipient has to open each one and guess the order. A neater approach is to merge the PDFs into one document and download it. This article also covers how to split, delete, and rotate pages and compress files.

Why merge PDFs in your browser?

  • No software needed — works on Windows, macOS, and phones, without installing Adobe Acrobat.
  • Your files never leave your device — on OneTool, PDF merging runs in your browser, and files are not sent to a server.
  • Free, no watermark — no account required.
Try the Merge PDF tool now Drag in 2 or more files, arrange them, click Merge and download. Open Merge PDF Online →

Common situations where you need to merge PDFs

  • Job applications — combine your CV, cover letter, diplomas, and certificates into one file.
  • Bid documents — business licenses, financial statements, and similar past contracts must be submitted in the required order.
  • Month-end invoices — gather e-invoices from multiple suppliers into one file to send to accounting.
  • Documents scanned in batches — scanners often save each scan as a separate file, so a 20-page application can end up spread across 5–6 files.

If part of your documents are phone photos, convert the images to PDF first, then merge.

How to merge multiple PDF files into one

  1. Open OneTool's Merge PDF Online page.
  2. Drag and drop the PDF files into the upload area, or click the area to select multiple files from your device.
  3. Click + Add PDF if any files are missing; the tool needs at least 2 files.
  4. Use the ↑ and ↓ buttons next to each file to change the order, and the × button to remove a file added by mistake.
  5. Click Merge PDF, wait for processing to finish, then click Download.

All pages of each file are joined in sequence, following the order in the list. The output file is named merged.pdf by default, so rename it before sending.

Tips for ordering and naming files so the order stays right

The tool merges in the order shown in the list; it doesn't sort by file name or creation date. So check the list once before clicking Merge.

  • Start file names with two-digit numbers, for example 01-CV.pdf, 02-bang-cap.pdf, because many file managers sort "10" before "2".
  • Give the output file a clear name, for example Nguyen-Van-A_Ho-so.pdf.
  • Open the downloaded file to make sure no part is out of order.

OneTool doesn't yet let you drag and drop individual pages within a file. To reorder pages, split the file into parts and then merge them back in the order you want.

Split PDF pages: keep only what you need to send

The Split PDF Online tool pulls one or a few pages into a new file, for example to send only the terms page instead of the whole contract. Upload the file, enter page numbers in the Pages to keep box, then click Split PDF.

  • Separate single pages with commas (2,5,9), use a hyphen for page ranges (1-3), and you can combine them, as in 1-3,5.
  • Page numbers count from the first page of the file, not from the numbers printed in the footer.
  • Pages are always output in ascending order, and a page entered twice appears only once.

Each split creates one file containing the selected pages. To split a PDF into separate single pages, run the tool again several times, entering one page number each time.

Rotate pages and delete extra pages

Scans that are upside down or sideways are a common problem when putting documents together. The Rotate PDF / Delete Pages tool lets you choose a rotation angle of 90°, 180° or 270° and the pages to rotate, for example 1,3-5.

  • Leave the Pages to rotate box empty to rotate every page.
  • The angle is added to the current orientation, clockwise; an upside-down page only needs a 180° rotation.
  • Use the Pages to delete box to remove blank or misplaced pages, for example 2,4; you can rotate and delete in the same run.

Keep the original file in case you need the deleted pages later.

Can I put 2 pages on 1 page?

Putting 2 pages on 1 means placing two pages side by side on one sheet. OneTool doesn't support this yet, because the Merge PDF tool only joins files.

As a workaround, open the PDF in Chrome or Edge, press Ctrl+P, choose Save as PDF and set Pages per sheet to 2. The option names may differ slightly depending on the browser.

Keep the file small enough to send by email or Zalo

A merged file is roughly as large as all the input files combined, so merging many scans often produces a heavy file. If needed, use Compress PDF Online before sending.

  • The Light level only optimizes the file structure, keeping text at its best, but usually saves little space.
  • The Recommended and Strong levels turn each page into a JPEG image, which saves a lot of space, but the text can no longer be selected or searched.

Typical file size limits for Zalo and email are covered in Compress a PDF for chat apps / email. If the file is still too large, split it into a few parts and send them one by one.

Privacy: where are files processed?

OneTool's merge, split, rotate and compress PDF tools use the pdf-lib and PDF.js libraries running right in your browser. Files are read and processed on your device and are not sent to OneTool's server.

Common errors and how to fix them

Password-protected files

A PDF with an open password is encrypted, so its pages may come out blank or broken in the merged file. If you have permission, open the file with the password and save an unlocked copy (for example by printing to PDF in your browser, if the file allows printing) before merging. You can then lock the whole file again with Password Protect PDF.

Pages rotated sideways or upside down

The merge tool keeps the page orientation of the original files. Note the numbers of the misaligned pages in the merged file, then rotate just those pages with the Rotate PDF / Delete Pages tool.

File too large

This is usually caused by high-resolution scans. Compress the merged file at the Recommended level, or compress each heavy file separately before merging.

Broken fonts or missing Vietnamese diacritics

Merging PDFs copies pages as they are, so it doesn't change fonts; font errors are usually already in the original file because it was exported to PDF without embedding fonts. In that case, export the PDF again from Word with the option to embed fonts.

Frequently asked questions

Is merging PDFs online free?

No. Merging, splitting, rotating, and compressing PDFs on OneTool are all free, with no account required.

Are my PDF files uploaded to a server?

No. Files are processed right in your browser and are not sent to OneTool's servers.

How many files can I merge at most?

There's no fixed limit; you just need at least 2 files. Slower devices or very large files will take longer to process.

How do I split a PDF into separate pages?

Run the Split PDF tool several times, entering one page number each time, for example 1, then 2, then 3.

Can I put 2 pages on 1 page?

OneTool doesn't support this yet. You can print to PDF from Chrome or Edge and set pages per sheet to 2.

How do I reorder pages within a PDF file?

Split the file into parts with Split PDF, then merge the parts back in the order you want with Merge PDF.
