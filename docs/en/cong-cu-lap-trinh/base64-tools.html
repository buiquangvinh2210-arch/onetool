How to use Base64 Encode / Decode

          
  1. Paste UTF-8 text (any language) or a Base64 string.
  2. Choose Encode or Decode, and turn on URL-safe / Data URL if needed.
  3. Copy or download the result — decoded images get a preview.

        
What is Base64?
Base64 encodes data (UTF-8 text, files, images) into a safe string to embed in JSON, HTML or URLs. OneTool uses the standard TextEncoder/TextDecoder — full Unicode support, not limited to ASCII.
How to encode / decode Base64
Encode tab: enter text or open a file, with optional URL-safe and Data URL modes. Decode tab: paste Base64 or data:image/…;base64,… — UTF-8 text is shown directly; images/files can be previewed or downloaded.
