Cách dùng Tạo phụ đề SRT

          
  1. Thả video MP4/MOV hoặc file MP3/WAV.
  2. Chọn tiếng Việt (hoặc tự nhận diện) rồi bấm Tạo phụ đề SRT.
  3. Tải file .srt và gắn vào CapCut, YouTube hoặc Premiere.

        
Phụ đề SRT là gì?
SRT là file phụ đề có số thứ tự, mốc thời gian và lời thoại. OneTool chuyển video / MP3 thành SRT tiếng Việt để gắn vào video đăng YouTube, TikTok (CapCut) hoặc Premiere.
Cách tạo phụ đề SRT từ video
Thả MP4, MOV hoặc MP3, chọn Tiếng Việt, bấm Tạo phụ đề SRT. Khi xong, tải `.srt` — có thể sao chép nội dung hoặc tải thêm bản TXT nếu cần sửa bài.
Dùng phụ đề SRT để làm gì
  • YouTube / Shorts upload SRT trong YouTube Studio để bật CC.
  • CapCut / Premiere kéo file SRT vào timeline, chỉnh câu cho khớp miệng.
  • Học / họp xem lại lời thoại có time-code thay vì nghe cả clip.

        
Câu hỏi thường gặp

          
Tạo phụ đề SRT online có miễn phí không?
Có. OneTool nhận diện giọng nói từ video hoặc MP3, xuất file SRT có time-code — không cần đăng ký.
Gắn file SRT vào đâu?
Kéo file `.srt` vào CapCut, Premiere, VNVE, hoặc tải lên YouTube Studio → Phụ đề. Một số trình phát video cũng nhận SRT cùng tên với file MP4.
File có bị lưu trên server không?
File được xử lý đám mây tạm thời để nhận diện giọng nói — không cần tạo tài khoản OneTool để dùng.
